Ajuda: Entendendo as Datas

Cada data tem um propósito específico para a gestão financeira:

  • Data de Competência: É a data em que a venda ocorreu ou o serviço foi prestado, independentemente do recebimento. É usada para o DRE (Demonstrativo de Resultados).
    Ex: A data da venda de uma peça no balcão.
  • Data de Vencimento: É o prazo combinado para o cliente pagar. Ajuda a controlar o que você tem para receber (contas a receber).
    Ex: O cliente levará o produto e pagará em 30 dias.
  • Data de Recebimento (Liquidação): É a data em que o dinheiro de fato entrou no seu caixa. É usada para o DFC (Fluxo de Caixa).
    Ex: O dia em que o cliente efetivamente pagou pela peça.
